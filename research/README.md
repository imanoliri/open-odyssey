# Sky Odyssey private research notebook

This directory records reproducible observations from a lawfully obtained copy
of the game. It is not a distribution point for the game or extracted content.

## Workflow

1. State a narrow question.
2. Define a repeatable setup and maneuver.
3. Record inputs and observable outputs.
4. Repeat the test and report variation.
5. Form a hypothesis.
6. Inspect runtime state only if observation is insufficient.
7. Translate the result into a behavioral requirement.
8. Implement independently in the public project.
9. Record whether the new implementation intentionally differs.

## Notebook conventions

- Use SI units when possible and document conversions.
- Separate observation from interpretation.
- Include emulator version, game region, save state, aircraft, upgrades, weather,
  and frame-rate settings.
- Never commit an ISO, BIOS, executable, save state containing copyrighted game
  data, extracted assets, music, dialogue, or videos.
- Store recordings and private dumps outside Git unless their inclusion has been
  reviewed.
