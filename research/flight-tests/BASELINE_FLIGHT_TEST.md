# Baseline aircraft flight test

## Purpose

Establish approximate behavioral ranges for one unmodified aircraft.

## Test matrix

| Test | Fixed conditions | Measured result | Repetitions |
|---|---|---|---:|
| Ground acceleration | Level runway, full throttle | Time/distance to reference speed | 3 |
| Takeoff | Neutral weather, same input | Speed/time at liftoff | 3 |
| Level turn | Fixed throttle and bank | Time for 360 degrees, altitude loss | 3 |
| Climb | Fixed entry speed and throttle | Sustainable climb angle/rate | 3 |
| Power-off glide | Fixed altitude and entry speed | Time, distance, descent rate | 3 |
| Stall | Level entry, gradual pitch increase | Indicated speed and warning behavior | 3 |
| Recovery | Same stall entry | Altitude and time lost | 3 |
| Landing | Same runway and approach | Tolerated sink, speed, alignment | 5 |
